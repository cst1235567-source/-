# Flappy Bird

A clean, single-file browser Flappy Bird built with vanilla JS + Canvas.

## Play

Open `index.html` in any browser — no build step required.

## Controls

| Action | Control |
|--------|---------|
| Flap | Click / Tap / Space |
| Restart | Click / Tap / Space after Game Over |

## Features

- Smooth canvas rendering with dark neon theme
- Animated bird with wing flap and tilt physics
- Procedurally generated pipes
- Score + local best score (persisted via localStorage)
- Responsive to keyboard, mouse, and touch
