# Bubble Bonk Carnival

A bright, candy-colored single-file browser flier built with vanilla JS + Canvas.

## Play

Open `index.html` in any browser — no build step required.

## Controls

| Action | Control |
|--------|---------|
| Flap | Click / Tap / Space |
| Restart | Click / Tap / Space after Game Over |
| Mute / Unmute | Top-right in-canvas icon or `M` |

## Features

- Four score-driven carnival levels with visual and gameplay shifts
- Original chibi hammer mascot rendered directly in Canvas
- Browser-safe procedural ambient music that starts after user interaction
- On-screen level HUD and mute toggle
- Smooth canvas rendering with bright skies, clouds, sprinkles, and candy pipes
- Score + local best score (persisted via localStorage)
- Responsive to keyboard, mouse, and touch
